# Kalkulator kosztów produkcji – wyroby garażowe

Prosta aplikacja webowa (jeden plik HTML, bez instalacji) do podliczania kosztów produkcji
garaży blaszanych, drewnianych, wiat, bram garażowych i podobnych wyrobów.

## Uruchomienie

Otwórz plik `kalkulator-kosztow.html` w przeglądarce (działa offline) lub przez GitHub Pages.

## Funkcje

- lista wyrobów z kosztem własnym na sztukę,
- koszty materiałów (ilość × cena jednostkowa, z procentem odpadu),
- robocizna (godziny × stawka; pusta stawka = stawka globalna),
- maszyny i energia (godziny × koszt godziny pracy),
- inne koszty (transport, montaż, cynkowanie, kooperacja),
- narzut kosztów ogólnych (globalny lub indywidualny dla wyrobu), marża, VAT,
- podsumowanie na sztukę i na całą serię, wykres struktury kosztów,
- porównanie z ceną sprzedaży (zysk w zł i %),
- automatyczny zapis w przeglądarce, eksport/import JSON, eksport CSV, wydruk kalkulacji,
- przykładowe dane do szybkiego startu.
